A propos de Comprendeshi

Le projet

Comprendeshi est un projet Flask intégrateur créé dans le cadre de l'apprentissage du framework Flask. Il implémente toutes les sections du tutoriel Flask de GeeksforGeeks dans une application professionnelle et structurée.

Technologies utilisées

  • Flask - Framework web Python
  • Flask-SQLAlchemy - ORM pour la base de données
  • Flask-Migrate - Migrations de base de données avec Alembic
  • Flask-Login - Gestion de l'authentification
  • Flask-WTF - Formulaires avec protection CSRF
  • Flask-RESTful - API REST
  • SQLite - Base de données (développement)
  • Docker - Containerisation

Sections du tutoriel couvertes

  1. Flask Quick Start (routes, variables, méthodes HTTP)
  2. Templates et fichiers statiques (Jinja2, héritage, filtres)
  3. Gestion des formulaires (Flask-WTF, validation, CSRF)
  4. Configuration par environnement
  5. Base de données (SQLAlchemy, migrations, CRUD)
  6. Middlewares (hooks before/after request)
  7. Authentification (Flask-Login, hashing, RBAC)
  8. API REST (JSON, pagination, filtrage)
  9. Fonctionnalités avancées (Blueprints, pagination)
  10. Gestion des erreurs et déploiement (Docker, Gunicorn)
