## 📚 Contexte du projet
Ce dépôt s’inscrit dans le cadre de mon apprentissage du **développement web back-end**, avec un focus particulier sur **Flask**, un micro-framework Python utilisé pour créer des applications web légères et modulaires.

L’objectif principal est de comprendre :
- les bases d’une application back-end,
- la logique client / serveur,
- la gestion des routes,
- la structure d’un projet Flask,
- et les premiers échanges entre le front et le back.
